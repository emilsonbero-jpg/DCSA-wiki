# EduPedia: Datamex College of Saint Adeline

A responsive, encyclopedia-style profile page for the Datamex College of Saint Adeline – Parañaque Campus. The site is built with plain HTML, CSS, and JavaScript and uses a light wiki-inspired design with a campus-photo background.

## Features

- Responsive page layout with article navigation and an institution infobox
- In-page article search with highlighted matches
- Table of contents that marks the section currently in view
- Campus photo used in the page background and heading banner
- No build step, framework, or package installation required

## Preview locally

Open `index.html` in a web browser. Keep the `assets` folder alongside it so the logo and background image load correctly.

## Publish with GitHub Pages

1. Push this project to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the site and the repository root (`/`) as the folder, then save.
5. Wait for the Pages deployment to finish and open the published URL shown in the Pages settings.
